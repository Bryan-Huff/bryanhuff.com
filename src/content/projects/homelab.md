## Overview

This homelab is my primary hands-on environment for developing practical skills in systems administration, networking, cybersecurity, virtualization, storage, automation, and infrastructure operations.

The environment is designed as more than a collection of self-hosted services. I use it to practice architecture design, implementation, troubleshooting, validation, documentation, and recovery workflows in a controlled environment.

## Current focus

Current work includes:

- Network segmentation and firewall policy with OPNsense
- Virtualization with Proxmox
- Containerized application hosting
- Self-hosted Git and documentation workflows
- Infrastructure documentation and architecture decisions
- Storage, backup, and recovery planning
- Security testing and future monitoring/automation work
